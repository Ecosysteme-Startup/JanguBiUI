# Maquettes de référence (version Lumière, clair et sombre)

Fichiers `.dc.html` exportés du canvas Claude Design « Jàngu Bi — Maquettes V1 » (polices Source Serif 4 + Libre Franklin).
Ce sont des **références visuelles** (HTML à styles en ligne), pas du code à importer. Les fichiers `Sombre-*` sont le mode sombre de l'écran du même nom.
Les couleurs y sont en dur : dans le code, utiliser les tokens `--jb-*` (`../design/tokens.css`). Correspondance des routes : `../02-SPEC-FRONT-V1.md` §2.

Pour les ouvrir : un navigateur suffit pour lire la structure et les textes ; le rendu fidèle se voit dans Claude Design.
